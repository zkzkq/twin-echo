## 1. 一句话概念与差异化卖点

### 1.1 High Concept

**《双影回响》**是一款幸存者like 割草 Roguelite：世界因时间崩塌而陷入"静滞潮汐"，玩家扮演能召唤自身残影的收割者，在铺天盖地的时间蚀怪群中生存 20 分钟。**你走过的每一步路都会在 2.5 秒后由"残影双子"重演——你的移动历史本身就是一名可构筑的队友。**本体与残影先后命中同一敌人会触发"共鸣击"，积攒共鸣值可释放全屏级主动技"同步爆发"。升级三选一、武器祭坛进化、局外回响密库天赋树，构成完整的单局与长线循环。

### 1.2 差异化卖点（为什么不是换皮）

| # | 卖点 | 一句话说明 | 对标现状 |
|---|---|---|---|
| S1 | **残影双子（核心创新）** | "走位即编队"：残影延迟重演你的位置与攻击，地图站位从被动躲闪变成主动构筑火力交叉 | 全品类无此核心动词；把幸存者like 最被诟病的"纯走位挂机"变成技能表达 |
| S2 | **共鸣系统** | 本体×残影双击同一目标=伤害加成+资源积攒，输出操作有明确正反馈回路 | 现有竞品的伤害成长几乎全靠数值叠加，缺少操作-奖励闭环 |
| S3 | **确定性进化（祭坛制）** | 进化条件透明（武器满级+搭档被动满级+精英掉落的结晶），在地图祭坛主动完成，走过去本身就是风险决策 | 对比《吸血鬼幸存者》开宝箱纯随机：尊重玩家时间，把"惊喜"留给升级三选一 |
| S4 | **双色可读性艺术方向** | 现实=暖琥珀、回响=青蓝，双影一目了然；品牌记忆点 | 大量像素割草同质化严重，视觉资产即传播资产 |
| S5 | **Premium 无内购** | 口碑位：一次买断，局外成长只靠游玩 | 对标手游化竞品的数值墙口碑风险，抢占"良心"心智 |

### 1.3 好玩假设（必须验证成立的唯一核心点）

> **假设 H1**：`走位编队 + 共鸣` 能在 30 秒内被新玩家本能理解，并在 3 分钟内产生"我掌控了两个自己"的掌控感爽点。
> 若 M1 试玩中该假设不成立（fun 评分 < 3/5），按 §12 Kill Criteria 迭代或重估创新方向——在此之前不投入内容生产。

## 2. 设计支柱（不可妥协的体验承诺）

后续一切设计决策以下列四条为标尺，违背即回炉：

| 支柱 | 承诺 | 反例（禁止） |
|---|---|---|
| P1 走位即决策 | 玩家每一秒的移动都在回答"残影该去哪" | 移动与输出无关的纯挂机流派成为最优解 |
| P2 共鸣可感 | 每次共鸣击都有即时音画反馈，音高随连击上行 | 共鸣只在后台算伤害、无可感知表现 |
| P3 可读的混沌 | 800 敌同屏时，伤害来源、威胁来源仍然可辨 | 全屏同色弹幕糊脸、敌我难分 |
| P4 尊重时间 | 单局 20 分钟、进化条件透明、局外无每日强制 | 体力制、限时商店、必要每日任务 |

## 3. 市场与竞品分析（2024–2025）

### 3.1 市场快照

- 品类在 Steam 上已高度拥挤（"吸血鬼幸存者like"标签作品数以千计），**品质门槛大幅抬高**：2024–2025 仍在爆的产品，都在至少一个维度做到了品类顶级或开创性。
- **2025 标志性事件**：3D 化幸存者like《Megabonk》成为爆款，Steam 销量突破 100 万份（[GamesIndustry.biz 报道](https://www.gamesindustry.biz/breakout-hit-megabonk-sells-more-than-a-million-copies-on-steam)），证明品类对新奇体验仍有强烈饥渴（[俄媒评测亦称其为"病毒式吸血鬼幸存者克隆"](https://ixbt.games/reviews/2025/10/13/my-dokatilis-do-takoi-industrii-videoigr-obzor-virusnogo-breinrot-rogalika-megabonk.html)）。
- **长青产品持续运营**：《吸血鬼幸存者》2024 年 10 月推出大型 IP 联动 DLC《Ode to Castlevania（恶魔城挽歌）》（[Steam 页面](https://store.steampowered.com/app/3210350/)），靠"超大内容量 + IP"维持热度。
- **Brotato（土豆兄弟）**：2024 年推出免费多人合作更新后热度回春；官方 DLC《Primal Dread》愿望单破 10 万（[Steam 公告](https://steamcommunity.com/games/1942280/announcements/detail/672867776636912182)）；续作《Brotato 2》仍是社区热议话题而非官方立项——**该团队策略是"小步 DLC+模式更新"而非续作**。
- **手游侧**：Habby《弹壳特攻队（Survivor.io）》跑通"割草×Roguelite×挂机 meta"后，多家厂商跟进，"玩转 Roguelike"的产品跑出千万级月流水（[创业邦报道](https://www.cyzone.cn/article/801139.html)）——手游变现在此品类极度成熟，但数值墙与广告疲劳也是口碑重灾区。
- **亚品类混融成为主流**：《Halls of Torment》以"每小时 5 万击杀的 Diablo"姿态融合暗黑装备带出局（[Ars Technica 评测](https://arstechnica.com/gaming/2024/10/halls-of-torment-is-diablo-cranked-up-to-50000-kills-hour/)）；《Death Must Die》融合 Hades 式恩赐三选一（[Game8 评测](https://game8.co/reviews/death-must-die/death-must-die-review)）；《HoloCure》以免费、超大内容量与 IP 粉丝系统成为免费标杆。

### 3.2 竞品对标表

| 竞品 | 核心优势 | 核心劣势 / 口碑痛点 | 对我们的启示 |
|---|---|---|---|
| 吸血鬼幸存者 | 极简操作、开箱惊喜、超值内容量 | 后期纯挂机无聊、进化靠宝箱运气 | 保底机制（S3）、后期超载设计（§8.4） |

| 弹壳特攻队 | 手游变现与投放教科书 | 数值墙、付费深、玩法更新乏力 | 引以为戒：Premium 无数值墙是我们的口碑定位 |
| HoloCure | 免费内容量天花板、粉丝/商店系统 | 依赖 IP 红利、不可复制 | 图鉴收集与金币商店结构可参考 |

| Megabonk | 3D 化新鲜感+玩梗传播力 | 3D 可读性/性能挑战 | **不跟进 3D**：我们押注机制创新（双影）而非维度切换，2D 像素保证可读性与性能预算（P3） |

### 3.3 机会点（我们的生态位）

1. **"主动化幸存者"**：品类最大口碑槽位是"后期挂机无聊"；双影+共鸣从核心动词层面解决，而非靠内容堆量。
2. **确定性+操作感的进化与主动技**：填补"宝箱随机疲劳"与"全程无按键"两个体验空白。
3. **Premium 口碑位**：在手游化与免费化夹缝中，"无内购买断制+高可读性"是社区传播友好定位。
4. **Web 原型即营销**：TypeScript+Web 技术栈让试玩链接即传播物料（io 式裂变），呼应 Megabonk 证明的"主播传播力"逻辑。
5. **风险对冲**：若 H1 失败，本设计的骨架（升级/进化/敌人/经济）仍可剥离创新层成为合格品类作品——创新层是增量而非全部赌注。

## 4. 核心玩法循环

### 4.1 即时循环（0–30 秒，战斗内心跳）

| 环节 | 内容 |
|---|---|
| 行为 | 移动引导残影形成交叉火力；对同一敌人完成本体×残影双击 → **共鸣击** |
| 反馈 | 共鸣火花 VFX + 五声音阶 chime（连击音高上行）+ 共鸣弧 UI 充能 |
| 奖励 | 共鸣击伤害 ×1.3；共鸣值 +6（满 100 可释放同步爆发）；敌人掉落 XP 宝石被磁吸拾取 |
| 情绪 | "我打了配合"——高频小胜利 |

### 4.2 单局循环（20 分钟标准局）

- **目标**：生存 20 分钟，击杀 20:00 终 Boss「时间织造者·诺诺」即胜利。
- **节拍**：5:00 / 10:00 / 15:00 小 Boss；每 2 分钟地图事件；8:00 / 13:00 / 18:00 进化祭坛刷新。
- **紧张感**：敌人密度与 HP 指数爬升（§7.4）；祭坛引导 2 秒不可受击（走位风险决策）；构筑在 18–20 分钟进入"超载时刻"——压力无限、火力全开。
- **结局**：
  - 胜利 → 时砂 ×(基础+100)，首胜额外奖励；
  - 被淹没 → 按存活分钟结算时砂（无惩罚性清零）。

### 4.3 局外 Meta 循环（数小时–数周）

| 环节 | 内容 |
|---|---|
| 成长 | 回响密库：5 支线 42 节点永久天赋（§6.8.2）；角色 8 名解锁；悖论难度 0–5 |
| 货币 | 时砂：单局结算产出 200–450 `[待测试]` |
| 留存钩子 | 每日挑战（固定种子+全局变异，排行榜+首通奖励）；武器/敌人/事件全图鉴收集；悖论等级逐级爬塔 |
| 情绪弧 | "这局差一点 → 用时砂点一个天赋 → 变强 → 换角色流派 → 打更高悖论" |

## 5. 核心创新机制规格书

### 5.1 机制：残影双子（Echo Twin）

| 字段 | 规格 |
|---|---|
| **目的** | 把"移动"升格为可构筑的输出系统；回答品类"挂机无聊"痛点 |
| **玩家幻想** | 与过去的自己组成双人舞：我走位，三秒前的我补刀 |
| **输入** | 玩家全部移动与攻击事件（自动记录，无需额外操作） |
| **输出** | 残影按延迟 D 重演位置与攻击；残影伤害 = 本体 × 0.6 `[待测试]`；残影命中同样施加共鸣标记 |
| **参数** | 延迟 D = 2.5s（角色/天赋可调 ±0.5s）；数量 1（天赋解锁第 2 条：延迟 5.0s，系数 0.35）；记录缓冲 150 逻辑帧 |
| **规则** | 残影**不拾取、不受击、不阻挡**；敌人索敌默认只锁定本体 `[待测试：若允许残影吸引索敌，将涌现"嘲讽流"，先禁用后观察]` |
| **成功判定** | 新玩家 3 分钟内未受教学即可自发利用残影补刀；共鸣覆盖率（共鸣击/总命中）达 30–45% |
| **失败状态** | 掉帧超过缓冲 → 残影进入跟随模式（贴随本体，系数不变）；地图传送/事件位移 → 残影淡出 0.5s 后重置到本体旁 |
| **边界情况** | 本体死亡 → 残影同时消散（局终）；残影与本体命中同一投射物系武器 → 各自独立结算，但同一敌人 1s 内只记一次共鸣标记来源配对；Boss 领域"残影延迟 +2s"（15:00 Boss 机制）作用于缓冲层，残影自动拉长延迟 |
| **调节杠杆** | 延迟 D、伤害系数、数量、缓冲帧数、索敌规则开关 |
| **依赖** | 移动/攻击事件系统；共鸣系统；性能预算（实体 ×2） |

### 5.2 机制：共鸣（Resonance）

| 字段 | 规格 |
|---|---|
| **目的** | 为双影提供操作-奖励闭环（支柱 P2） |
| **判定** | 同一敌人在 1.0s 窗口内先被本体命中、再被残影命中（或反之）→ 该次伤害 ×1.3，产生共鸣火花，共鸣值 +6 |
| **资源** | 共鸣值 0–100，仅用于同步爆发；每局开始清零 |
| **成长** | 被动「共振」：共鸣伤 +10%/Lv（乘区上限 +100%）、共鸣值获取 +8%/Lv |
| **成功判定** | **共鸣击频率 50–120 次/分**（即每 0.5–1.5 秒一次共鸣火花）；覆盖率（共鸣击/总命中）降级为**诊断量**，参考区间 10–25% |
| **失败状态** | 窗口内重复命中同一配对不重复计值（防抖）；残影消散时未结算配对自然过期 |
| **调节杠杆** | 窗口时长（1.0s）、加成 ×1.3、单次共鸣值、**共鸣击频率 KPI** |

> **v0.2 口径变更说明（重要，勿回退）**：原 KPI「共鸣覆盖率 30–45%」在 M1 实测中始终落在 8–20%；引擎内 A/B 实验（4 臂 × n=5）进一步证明**缩短延迟（2.5s→1.8s）与放大残影射程（×1.5）都无效**（覆盖率 16.6% vs 16.5% vs 7.8%）——因为覆盖率分母被 AoE 武器的海量命中实例撑大，而共鸣是"每敌一次配对"，该比值在结构上不可达；单侧放大残影射程还会因分母膨胀而**下降**。
> 共鸣击**频率**直接度量"玩家多久看到一次共鸣"，与本节目的（共鸣可感，支柱 P2）一致：实测基线 88–116 次/分 ≈ 每 0.5–0.7 秒一次火花。故 v0.2 起以频率为主 KPI，**不再通过调延迟/射程去追覆盖率**。详见 `docs/M1-实测与调参记录.md` §9。

### 5.4 机制：编队走位（双影夹击 + 回响同步，M3 新增）

> **为什么要有这一节**：M3 的机器人对照实验证明，原本的数值结构里**谨慎/编排走位没有任何正收益**——"躲得好"不如"贪宝石练级"（详见 `docs/M1-实测与调参记录.md` §21、§23）。支柱 P1 是"走位即编队"，若走位本身不给回报，这条支柱只是口号。故 M3 引入两条**只奖励位置编排**、不奖励"跑得远"的机制。

| 机制 | 判定 | 收益 | 设计意图 |
|---|---|---|---|
| **双影夹击（Pincer）** | 同一敌人先被一侧命中、再被另一侧命中，且两次来源位置与敌人的夹角 **> 120°** | 该次共鸣伤害 ×1.35、共鸣值 ×1.5 | 把"残影跟着你"变成"把敌人夹在两个你之间"；远程武器（裂空弩/双生棱镜）最容易打出来 |
| **回响同步（Sync）** | 本体与残影距离 ≤ **130px**，且**连续保持** | 按下表随连续时长叠加 | 残影重演的是你 2.5s 前的位置，"贴住残影"＝**走回环/绕圈**——恰好也是待在已清空口袋里的走法 |

**回响同步 ramp**（`BAL.resonance`，每连续 1s 叠 +7.5%，8s 触顶）：

| 连续同步时长 | 1s | 3s | 5s | 8s（上限） |
|---|---|---|---|---|
| 伤害 / 共鸣值 / 拾取半径 | +7.5% | +22.5% | +37.5% | **+60%** |
| 受伤减免（回响护体） | −3% | −9% | −16% | **−25%** |
| 残影周围敌人移速（回响阻尼，半径 140px） | −3% | −9% | −16% | **−25%** |

- **断同步即清零**：所以只有"承诺编队"才拿得到满额，顺带同步不构成强度。
- **实测依据**：同一机器人、机制开 vs 关的对照（n=5）＝存活 **4.11min vs 3.48min（+18%）**、等级 15.0 vs 12.6；机制开启后编队流与"贪宝石"基线打平（4.11 vs 4.27min）。**关键在"回响阻尼"这条防守收益**——只给伤害/共鸣值时对照差仅 +0.20min（噪声内），补上阻尼后才变成 +0.63min。
- **两条机制的诊断量**：夹击频率（次/分）、同步时间占比（%）与最长连续同步（s）均写入遥测与结算页。

### 5.5 机制：同步爆发（主动技，键位 空格/E）

| 字段 | 规格 |
|---|---|
| **目的** | 给玩家一个主动按键时刻，打破"全程无操作"的品类惯性；后期压力阀 |
| **输入** | 共鸣值满 100 后手动释放（不自动） |
| **输出** | 以本体为中心 r=360px 的时空对冲波：伤害 = 面板 DPS ×4 `[待测试]`、清除敌方弹幕、敌人减速 40% 持续 3s |

| **调节杠杆** | 半径、倍率、减速时长、共鸣值获取速率 |

### 6.4 升级三选一（受控随机）

### 6.8 经济与局外成长

#### 6.8.1 货币：时砂（单局产出）

```
时砂 = floor( 存活分钟 ×10 + 击杀数/80 + 精英×5 + Boss×20 + (胜利?100:0) )
       × (1 + 贪婪%) × (1 + 0.1 × 悖论等级)
```

样例：15 分钟失败局（击杀 2,700、精英 3、Boss 2）→ 150+33+15+40 = **238 时砂**；20 分钟胜利局 → **447 时砂**。目标区间 200–450/局 `[待测试]`。

#### 6.8.2 回响密库（永久天赋，42 节点 = 6 支线 × 7 深度）

节点花费按支线内深度 d：`cost(d) = 30 × 1.4^d`（30/42/59/82/115/161/226）；深度 ≥5 的节点给了**两条效果**，让深支线值得投资。

> **v0.3 实现对齐**：M3 把 M2 的 18 节点骨架补齐为 **42 节点（6 支线 × 7 深度）**，并把原先"描述写两条、实际只生效一条"的节点（时相核心 / 命运之轮 / 织者印记）改成**真正的双效果**（`effect2`/`value2`）。原草案的"第二残影""开局预设构筑"等大机制顺延 EA。

### 7.1 经验曲线

**单级需求**：`XP(l→l+1) = round( 6 + 4.5 × (l−1)^1.4 )`

| 到达等级 | 单级需求 | 累计需求 |
|---|---|---|
| L2 | 6 | 6 |
| L5 | 37 | 62 |
| L10 | 104 | 373 |
| L15 | 187 | 1,052 |

| L40 | 766 | 12,208 |

**收入模型**：20 分钟总击杀 ≈ 3,200–3,600；宝石四档：蓝 1 / 绿 6 / 金 36 / 虹 216；**合并规则：同屏同级 ≥5 → 合并为 1 上级（+20% 合并奖励）**；精英掉金宝石 ×5，Boss 掉虹 ×1。

### 7.2 宝石与拾取

- 磁吸半径基础 80px（磁引被动/meta 提升）；磁吸为加速吸附（0.3s 内飞向玩家），防止"宝石尾巴"拖沓。
- 同屏拾取物上限 500，超出即触发强制合并（性能护栏）。

### 7.3 伤害公式

```
最终伤害 = round(
    基伤 × (1 + 0.10 × (武器Lv−1))      // 武器成长
  × (1 + 力量加成)                      // 被动/天赋乘区
  × 暴击倍率                             // 期望值 = 1 + 暴率 × (暴伤 − 1)
  × (1 + 共鸣加成)                       // 仅共鸣击，乘区上限 +100%
  × 距离衰减系数                          // 锥射/落体类 0.6–1.0
)
实际伤害 = 最终伤害 × (1 − 减免率)
减免率 = 敌甲 / (敌甲 + 80 + 12 × 经过分钟)     // 时间缩放，防止后期护甲失效或过强
```

**演算示例**：时钟指针 Lv4（基伤 12×1.3=15.6）+ 力量 Lv3（+24%）+ 会心 15%/1.8×（期望 ×1.12）+ 共鸣击（×1.3）vs 敌甲 10@10min（减免率 10/210≈4.8%）：
`15.6 × 1.24 × 1.12 × 1.3 × 0.952 ≈ 26.9 → 27 伤/次` ✓ `[待测试]`

### 7.4 难度曲线（生成与成长）

**敌人 HP 成长**：`HP(t) = 14 × (1 + 0.18 × 分钟数)^1.35`

| 分钟 | 1 | 3 | 5 | 8 | 10 | 13 | 15 | 18 | 20 |
|---|---|---|---|---|---|---|---|---|---|
| 基础敌 HP | 18 | 25 | 33 | 47 | 56 | 71 | 82 | 98 | 110 |

| 在场上限 | 120 | 180 | 240 | 320 | 380 | 450 | 520 | 580 | 600 |

- **双轨通胀**：敌人 HP 20 分钟 ×6，玩家 DPS 预算 ×6.7（见 §7.5）——玩家成长略快于敌人 HP，**数量与密度承担压力**，保证"越打越爽"的通胀方向正确。
- 碰撞伤害：每敌对玩家 0.8s 一次（被围 = 死亡，符合品类惯例）；玩家 HP 100，敌弹 12–18。
- 移速：玩家 190 px/s；敌 45–160（冲刺 320）——**玩家永远跑得比大多数敌人快**，走位可解是底线。

### 8.2 随机性原则：输入随机可规划，输出随机可_scale

| 随机源 | 类型 | 设计处理 |
|---|---|---|
| 敌人生成位置/波次 | 输入随机 | 可读预兆（生成环红光 0.5s），玩家可规划路线 |
| 三选一选项 | 受控随机 | 命运加权保底 ≥1 项可用；重掷/放逐兜底 |
| 暴击 | 输出随机 | 可被会伤流规模化成构筑而非运气 |
| 精英光环/事件 | 输入随机 | 事件每 2min 固定 1 次，可预期 |

**原则**：不设计"玩家无法用策略覆盖的纯惩罚随机"（无即死陷阱、无隐形单位）。

### 8.3 决策密度 KPI

每 45 秒至少 1 个有意义决策（升级选择 / 事件取舍 / 祭坛路线 / 爆发时机）。遥测：`decision_moments` 埋点校验；若中位间隔 >70s → 增加事件频率或祭坛交互。

### 8.4 防后期无聊的三重手段

1. **超载时刻**（18–20min）：密度上限 + 构筑完全体 = 无脑爽回收，用"释放"替代"疲惫"。
2. **主动技循环**：同步爆发让后期仍是"玩家在玩"，不是数值在跑。
3. **构筑终点差异**：6 进化流派 + 9 角色特性，保证第 10 局与第 1 局的操作节奏不同；悖论等级提供"规则变化"而非纯数值变化。

### 8.5 行为经济学使用红线（道德设计）

- **可用**：禀赋效应（图鉴命名/收藏）、可变奖励（金色选项、结晶掉落）、承诺机制（每日 streak 仅奖励外观）。
- **禁用**：限时 FOMO 商店、体力/门票、每日强制任务、离线惩罚、付费数值。

## 10. 美术与主题方向

### 10.1 世界观与主题

时间崩塌后的世界「静滞潮汐」：时钟停摆，被时间锈蚀的造物（时蛾、蚀刻像、跳针…）追逐唯一还在"现在"的人。玩家的残影是"刚刚过去的自己"——**主题与机制同构**（双影=时间的回响），叙事不做长文本，全部机制内叙事。

### 10.2 视觉方向

- **风格**：2D 像素俯视（tile 16×16，角色 32×32，4 向 8 帧走位 + 2 帧待机），哥特钟表朋克 × 霓虹蓝调。
- **双色世界规则（S4 品牌资产）**：现实层 = 暖琥珀/铜（#E8A33D 系）；回响层 = 青蓝/银（#4FD8E0 系）。所有与"残影/时间"相关的元素一律青蓝系。
- **可读性规则（P3，不可妥协）**：
  1. 玩家：饱和暖色 + 2px 白描边；残影：55% 透明青蓝 + 波纹描边 + 拖尾——同屏任意时刻可 0.5s 内分辨本体/残影；
  2. 敌人：剪影唯一性优先（弱内部分色），8 基础型剪影两两不同；
  3. 弹幕按元素配色，敌方弹幕一律暖红边（与玩家冷色弹幕区分）；
  4. 命中反馈三档：普通（白闪）→ 暴击（击退+放大 1.1×）→ 共鸣击（双色火花 + 音阶）。
- **VFX 预算**：同屏粒子 ≤1,500；全屏震 ≤0.15s / 4px，仅 Boss 技与同步爆发可用；死亡溶解统一为"时间碎片"粒子（复用）。

### 10.3 音频方向

- 共鸣 chime 采用五声音阶（C-D-E-G-A）随连击上行——**音效即连击计**（可盲玩感知构筑强度）；
- 同步爆发：低频对冲波 + 0.3s 静默（ducking）；
- Boss 主题换拍（3/4→4/4）标记阶段切换；音效优先级表：共鸣 > Boss 预警 > 拾取 > 环境音。

### 10.4 UI

极简 HUD：底部 XP 条（VS 惯例位置）、左上 HP 环、右上 时钟+分钟刻度（主题化怀表）、下中 共鸣弧 + 爆发键提示、左下 武器/被动格。三选一面板：卡片带协同标签角标（服务命运加权的可读性）。

### 10.5 输入方案（M3 实装：键盘 + 鼠标双方案）

| 输入 | 行为 | 设计说明 |
|---|---|---|
| **WASD / 方向键** | 八向移动，斜向自动归一化 | 默认方案；与残影 2.5s 延迟的"回环走位"配合（§5.4 回响同步） |
| **鼠标左键按住** | 朝光标**满速**移动；松手立刻回到键盘 | 临时跟随，两种输入可随时混用，不需要设置项 |
| **鼠标右键单击** | 切换「常驻跟随」（长局不必一直按着） | 20 分钟局的手部舒适度需求 |
| **光标死区 26px** | 光标落在角色 26px 内则停下 | 防止"光标压在角色身上"时原地抖动 |
| **面向 = 光标方向** | 使用鼠标时朝向跟随光标（即使站定） | 定向武器（钟摆镰 / 时之沙暴）在不移动时也能瞄准 |
| 准星 | 世界坐标上的金色小圈，随相机跟随 | 让"操控目标点"可见；不显示时不占注意力 |

**关键取舍**：鼠标**不做距离比例调速**（靠近光标不等于减速）——走位距离是数值平衡的一部分（§7.4 玩家 190px/s 是"可解"的底线），让鼠标能"半速挪步"会引入键盘玩家没有的优势。同理，鼠标方案不改变任何速度/半径参数，只替换**方向来源**。

> 实现提示（踩坑）：光标坐标必须**先存屏幕像素、由 World 在 update 时用当前相机换算**。相机每帧跟随玩家移动，提前换算会滞后一帧；且屏震（随机偏移）不能进换算，否则准星会随屏震抖动。

## 11. 技术选型建议

### 11.1 对比与推荐

| 方案 | 优势 | 劣势 | 适用场景 |
|---|---|---|---|
| **TypeScript + PixiJS（WebGL2）+ Vite** ★推荐 | 迭代最快、浏览器即试玩（链接=传播物料）、热重载调参、无引擎税 | 需自建存档/成就/Steam 封装（Electron/Tauri）、无内置编辑器 | Web/Steam EA 优先、小团队、本设计的 MVP |
| Godot 4 | 优秀 2D 工作流、GDScript 快速、MIT 免费、导出全平台 | 性能上限低于手写 WebGL 的极限优化、Web 导出包体偏大 | 团队熟 Godot 或需主机端 |
| Unity 6 | 生态最全、手游商店/买量链路成熟 | 2D 割草的性能需自行优化、版本噪音 | 手游优先或团队 C# 背景 |

**决策树**：目标 Steam EA + Web 传播 → **PixiJS**；手游优先/重度变现 → Unity（或 Cocos）；GDScript 熟练 → Godot。**本设计选 PixiJS 路线**：MVP 验证期速度 > 一切，且 Web 原型本身是营销资产（§3.3 机会点 4）。

### 11.2 架构要点（割草品类的性能即设计）

- **固定步长 60Hz 逻辑 + 渲染插值**（掉帧不改变平衡）；ECS-lite（数据组件 + 系统函数，不上重型框架）。
- **空间哈希网格**（cell 64px）做碰撞/邻域查询；敌人分离力用抽样邻居（≤6）的 boids-lite，避免 O(n²)。
- **对象池全覆盖**：敌人/弹幕/宝石/VFX 零运行时分配；纹理图集 ≤4 draw call。
- **实体预算**：桌面 600 敌 + 400 弹 + 500 拾取 @60fps（中端核显）；移动端 cap 350/250/300。
- **残影实现**：位置/朝向/攻击事件环形缓冲（150 帧），重放层与本体同一武器系统代码路径（保证平衡一致），伤害系数独立。
- **数据驱动**：武器/被动/敌人/事件全 JSON 表 + 开发热重载；调参 schema 与 §16 对齐；Node 脚本跑蒙特卡洛（200 seed 回归）验证 §7 验收区间，接入 CI。
- **存档**：MVP localStorage + 导出码 → Steam Cloud（Tauri/Electron 封装后）。
- **埋点**：本地 CSV（MVP）→ 匿名遥测（EA 后），事件清单见 §14。

## 14. 测试计划与遥测 KPI

**测试节奏**：M1 起每周 1 轮 5–8 人小样（观察+访谈），区分观察记录（发生了什么）与解读（意味着什么）；M2 起 50 人封测带埋点。

**埋点事件**：`run_start/end`、`death_time_pos`（死亡热图）、`levelup_choice/skip`（放弃率）、`resonance_hit`（覆盖率）、`burst_cast`（爆发间隔）、`altar_reach/craft`（祭坛到达率/选择）、`event_outcome`、`meta_spend`。

**KPI 阈值（越界即排调参任务）**：

| KPI | 目标 | 报警线 |
|---|---|---|
| 死亡中位分钟 | ≥11 | <9 |
| 升级放弃/跳过率 | <8% | >15% |
| **共鸣击频率**（v0.2 主 KPI） | 50–120 次/分 | <25 或 >200 |
| 共鸣覆盖率（诊断） | 10–25% | 不设报警 |
| 祭坛到达率 | ≥80% | <60% |
| 爆发释放间隔（熟练玩家） | 60–90s | >150s |
| 时砂/局 | 200–450 | >550（通胀） |
| 3 日回访（封测） | ≥35% | <20% |

### 14.1 验收度量工具（M3 实装：三条 Exit Criteria 的仪器）

M3 的三条 Exit Criteria（中位局时长 ≥18min / 3 日回访 ≥35% / 崩溃率 <0.5%）此前**没有任何度量口径**，这轮把仪器补齐了——否则数据回来也没法判"过没过"：

| 指标 | 数据来源 | 计算口径 | 取数方式 |
|---|---|---|---|
| **中位局时长** | 遥测每局 `time` + 诊断模块 `runSeconds` | 全部局存活秒数的**中位数**（不是平均：平均会被超长局拉偏） | 标题页「导出验收报告」/ `pnpm telemetry` |
| **3 日回访** | 诊断模块 `playDays`（本地日期去重升序） | 以首个游玩日为 D0，D1–D3 内是否还有游玩日（同时给出 D1/D3/D7 与最大间隔） | 报告里的原始 `playDays` 可离线聚合多人 |
| **崩溃率** | 诊断模块 `sessions` / `crashes` | **异常会话 / 总会话**；"异常会话"= 上一次会话没有在 `pagehide` / `visibilitychange(hidden)` 正常收尾（浏览器崩溃 / 标签被杀 / 进程强杀 / GPU 上下文丢失都会留下 `clean=false` 残留） | 同报告 |
| 捕获异常（辅助） | `window.onerror` / `unhandledrejection` | **单独计数**，不混入崩溃率（否则一次网络抖动就污染分母） | 报告"最近异常"区 |

- **实现**：`src/core/diagnostics.ts`（会话/崩溃/游玩日/每局时长 + 报告生成）、`scripts/summarize-telemetry.mjs`（CSV 侧汇总 + 三条 Exit Criteria 判定）。
- **试玩流程**：每位试玩者跑完自己的局数后点标题页「**导出验收报告**」→ 得到一份 `twin-echo-acceptance-*.md`（含三条指标现状、原始游玩日、最近异常）→ 回收后 `pnpm telemetry` 一起汇总。
- **隐私**：所有数据只写 localStorage，只有玩家主动点导出才落文件（无网络上报）。

### 14.2 调试工具：作弊码（M3 实装）

**入口**：暂停面板（Esc）→「作弊码」输入框（回车执行）· 输入 `HELP` 在面板里列出全表。

| 码 | 名称 | 效果 | 可重复 |
|---|---|---|---|
| `HEAL` | 回响续命 | 生命回满 + 3 秒无敌 | ✓ |
| `MAXWEAPON` | 针针满级 | 当前持有的武器全部 Lv6 | ✓ |
| `ALLWEAPON` | 十二时相 | 一次入手全部 12 把武器（Lv6） | ✓ |
| `MAXPASSIVE` | 满编回响 | 15 项被动全部 Lv5（属性重算） | ✓ |
| `EVOLVE` | 六重织造 | 直接获得全部 6 件进化体（自动补齐武器/被动） | — |
| `LEVELUP` | 时间加速 | 直接 +10 级（含每级回复） | ✓ |
| `KILLALL` | 静止潮汐 | 清空场上所有非 Boss 敌人（掉落照常） | ✓ |
| `FREEZE` | 时停 | 全场敌人定身 8 秒 | ✓ |
| `GOD` | 回响不灭 | 切换免伤 | ✓ |
| `GAUGE` | 共鸣满溢 | 共鸣值立刻充满 | ✓ |
| `NOFOG` | 开卷 | 切换无视视野遮蔽（图书馆调试） | ✓ |
| `BOSS` | 织造者降临 | 立刻召唤下一只 Boss（跳过日程） | ✓ |
| `WEAVER` | 终末提前 | 立刻召唤 20:00 时间织造者·诺诺 | — |
| `SANDBAG` | 时砂满仓 | 时砂 +99999（局外货币，立即存档） | — |
| `METAFULL` | 密库全开 | 解锁全部 42 个密库节点 | — |
| `WIN` | 时间为你停留 | 立刻结算胜利（演示/验收用） | — |
| `KONAMI` | 残影之友 | 彩蛋：满血 + 全武器满级 + 被动满级 + 共鸣满 + 时砂 +3000 | — |
| `HELP` | 作弊码清单 | 列出全部作弊码 | ✓ |

- 输入**大小写/空格/连字符不敏感**；别名（`HP`/`MAXW`/`EVO`/`STASIS`/`↑↑↓↓←→←→BA` 等）等价。
- **作弊局隔离（硬约束，别绕过）**：一旦用过任何作弊码，本局置 `world.cheated = true` →
  ① **不计成就**（否则 `ALLWEAPON`/`LEVELUP` 会把武器与等级成就直接刷出来）；
  ② **不更新历史最佳**（`saved.runBest`，那是成就面板的进度来源）；
  ③ **不进验收报告的中位样本**（只计入"作弊局 N 局"，报告里明确标注排除）；
  ④ 遥测行带 `cheated: true`，结算页与 HUD 各有一处 ⚑ 标记；
  ⑤ 沙与时砂**照给**——单人玩具里拦不住（`SANDBAG` 直接给钱），也不值得拦。
- 实现约定：所有作弊码必须走 `applyCheat()`（归一化 → 查表 → 不可重复检查 → 标记 → 遥测）；`src/game/cheats.ts` 不 import Game，特权能力（加时砂/解锁密库/强制胜利/召唤 Boss）由 `CheatCtx` 注入，避免循环依赖与私有字段穿透。
