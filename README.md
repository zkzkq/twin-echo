# 双影回响 Twin Echo — M1 战斗原型

2D 俯视角幸存者like 割草 Roguelite 的最小可玩原型（对应《双影回响》GDD §12.1 验证集）。

**核心机制**：残影双子（2.5s 延迟重演你的移动与攻击）× 共鸣击（本体×残影 1s 内双击同一敌人）× 同步爆发（共鸣值满 100 主动释放）。

## 运行

```bash
pnpm install
pnpm dev        # http://127.0.0.1:4173
pnpm build      # tsc 类型检查 + vite 构建 → dist/
pnpm sim        # M0 解析模型：节奏推演（击杀/分 · 终局等级 · 同屏峰值）
pnpm smoke      # headless 端到端冒烟：33 项断言（需 dev server 已启动）
pnpm probe      # 引擎内节奏探针：机器人真打一局并逐分钟采样
pnpm bench      # 性能压测：300 敌稳态下测逻辑/渲染耗时（BENCH_BUILD=max / BENCH_PROF=1）
pnpm mc         # 蒙特卡洛回归门禁：连跑 N 局并对照回退阈值
pnpm ab         # 共鸣几何 A/B 实验（延迟 vs 残影射程）
pnpm telemetry  # 汇总试玩回收的遥测 CSV → KPI 报告
pnpm nightly    # 本地完整回归：tsc → build → smoke → mc（CI 为手动触发的 .github/workflows/regression.yml）
```

> 端口说明：默认 5173 落在 Windows 保留端口区（5134–5233，由 Hyper-V/WSL 预留），故改用 4173。

**性能剖析**：引擎内置分相剖析器（dev-only，`BENCH_PROF=1` 启用，默认零开销），输出各子系统耗时与**未归因时间**——
未归因大 ⇒ 环境/GC 问题，某相大 ⇒ 引擎热点。`separation` 当前最贵（0.10ms/帧）。

> 测试基建注意点（已踩坑）：无头浏览器**必须杀进程树**（`taskkill /T`，否则残留僵尸，实测累积到 121 个）；
> 调试端口**随机化**（僵尸实例会占住固定端口让 WebSocket 悬死）；长跑 dev server 会**给出过期模块缓存**，
> 改文件后用 `pnpm smoke` 复验（必要时 `vite --force` 重启）。**dev server 的 esbuild 警告要看**——
> 重复 case 分支会静默变成死代码（TS 不报错）。**性能结论必须在干净环境复测**：曾因濒死 dev server +
> 僵尸进程测出 2.8s"引擎毛刺"，干净环境复测为零未归因时间。
> **别用 PowerShell 的 `Get-Content`/`Set-Content` 改这些中文文档**：一旦被按 ANSI 读进来再写回，全文会变成
> 乱码（本轮真的踩到一次，只能 `git checkout -- docs/...` 恢复）；改 md 一律用文件编辑工具。
> 另外：**非每日局的开局种子是随机的**，任何"30s 时等级 ≥N"这类断言都会偶发抖动——冒烟里已把战斗预热
> 拉到 40s 并挑选"最孤立障碍"来消除两处随机性导致的假失败。
